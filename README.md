<h1 align="center">🌙 goome app template: Lua 🌙</h1>

<p align="center">
<b>A tiny goome app in Lua to start from. A normal window, and one toggle turns it into an overlay on top of everything.</b>
</p>

<details>
<summary align="center"><b>🚀 Make Your Own 🚀</b></summary>

<br>

<p align="center">
<b>Use this template</b> on GitHub gives you this repo as it is. With goome-cli you pick the name and which template you want:
</p>

```sh
pip install git+https://github.com/goome-ui/goome-cli
goome new my-thing --lang lua
goome new my-thing --lang lua --template hud
```

<p align="center">
It swaps "My Goome App" and friends for your name everywhere, files too, and leaves out the template only stuff.
</p>
</details>

<details>
<summary align="center"><b>🔨 Build And Run 🔨</b></summary>

<br>

<p align="center">
You need Lua 5.4 or LuaJIT, <a href="https://luarocks.org/">LuaRocks</a> and a C compiler (gcc, clang, or Visual Studio / mingw on windows). goome isnt on the luarocks.org server, so <code>goome-0.5.5-1.rockspec</code> in here is the one from the <a href="https://github.com/goome-ui/lua-goome/releases">lua-goome release</a>. LuaRocks grabs v0.5.5 with git and builds it once, that takes a few seconds.
</p>

```sh
luarocks install --local goome-0.5.5-1.rockspec
eval "$(luarocks path)"          # on windows run luarocks path and do what it prints
lua main.lua
```

<p align="center">
If your luarocks installs system wide just drop the <code>--local</code> and the <code>luarocks path</code> line. Add <code>--lua-version 5.1</code> for a LuaJIT tree.<br>
To update goome swap the rockspec for the one on the newest <a href="https://github.com/goome-ui/lua-goome/releases">lua-goome release</a>.
</p>
</details>

<details>
<summary align="center"><b>🧩 Other Templates 🧩</b></summary>

<br>

<p align="center">
<code>variants/</code> has the other starting points. Each one is the file that replaces <code>main.lua</code>:<br> <br>
<b>overlay</b> - a see-through overlay over the whole desktop, only the window takes clicks. alt+h hides it<br>
<b>mod-menu</b> - a menu with toggles and sliders over whatever game is running, alt+m opens and closes it<br>
<b>hud</b> - a little panel in the corner with the time and fps, every click goes straight through it<br><br>
<code>goome new</code> puts the one you pick in place for you. By hand, copy the file over <code>main.lua</code> and delete <code>variants/</code>.
</p>
</details>

<details>
<summary align="center"><b>🧪 Testing Without A Screen 🧪</b></summary>

<br>

<p align="center">
goome has a test backend that fakes a whole screen, so the app runs in CI with nothing on screen. The script says what the "user" does and you get a screenshot of every frame in <code>shots/</code>. This one clicks the toggle:
</p>

```sh
GOOME_BACKEND=test GOOME_TEST_SHOTS=shots/ GOOME_TEST_SCRIPT="screen 1280x720 1; 3 click 60,28; end 6" lua main.lua
```

<p align="center">
CI does that on linux, windows and mac on every push. The script format is in the <a href="https://github.com/goome-ui/c-goome/blob/main/docs/DESIGN.md">c-goome docs</a> under Test.
</p>
</details>
